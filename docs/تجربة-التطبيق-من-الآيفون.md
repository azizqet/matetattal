# تجربة «ماتعطل» من الآيفون فقط (بدون كمبيوتر)

كل الخطوات من Safari وتطبيق Expo Go. تحتاجها **مرة واحدة فقط**. بعدها كل تعديل جديد يُنشر تلقائياً.

## الخطوة 1: تطبيق Expo Go وحساب Expo
1. حمّل **Expo Go** من App Store.
2. افتحه، واضغط أيقونة الحساب أعلى الشاشة، ثم **Sign up** وأنشئ حساباً مجانياً.

## الخطوة 2: إنشاء رمز وصول (Token)
1. في Safari افتح: https://expo.dev/settings/access-tokens وسجّل دخولك بنفس الحساب.
2. اضغط **Create token** وسمّه مثلاً `github`.
3. انسخ الرمز. يظهر مرة واحدة فقط.

## الخطوة 3: حفظ الرمز في GitHub
1. في Safari افتح: https://github.com/azizqet/matetattal/settings/secrets/actions
2. اضغط **New repository secret**.
3. الاسم: `EXPO_TOKEN`، والقيمة: الرمز الذي نسخته. ثم **Add secret**.

> الرمز يبقى سرياً داخل GitHub، ولا يظهر في الكود ولا في السجلات.

## الخطوة 4: نشر نسخة التجربة (بموافقتك فقط)
لا يُنشر أي تحديث تلقائياً. النشر يحدث فقط عندما تضيف أنت الوسم:
1. افتح Pull Request رقم 1: https://github.com/azizqet/matetattal/pull/1
2. من **Labels** أضف الوسم `expo-preview` (إضافته تعني موافقتك على النشر).
3. خلال 3–5 دقائق يظهر في الـ PR تعليق فيه رابط التحديث ورمز QR.
4. ما دام الوسم موجوداً، كل تعديل جديد على التطبيق يُنشر تلقائياً. أزل الوسم لإيقاف النشر.

## الخطوة 5: فتح التطبيق
- افتح **Expo Go** وتأكد أنك مسجل الدخول بنفس الحساب.
- ستجد مشروع **matetattal** في الشاشة الرئيسية. افتحه واختر آخر تحديث على الفرع `preview`.
- أو اضغط رابط التحديث الموجود في تعليق الـ PR، فيفتح في Expo Go مباشرة.

## ملاحظات
- Expo Go للتجربة فقط. النسخة النهائية للمتاجر تُبنى عبر EAS Build.
- اتجاه الواجهة من اليمين لليسار يعمل في Expo Go حتى لو كانت لغة الآيفون إنجليزية.
- تحديد الموقع والاتصال والواتساب واختيار الصور كلها تعمل داخل Expo Go.
- إذا ظهرت رسالة «Project is incompatible with this version of Expo Go»: حدّث Expo Go من App Store (التطبيق مبني على SDK 58).
