# ماتعطل v5 — سوق الكويت للإعلانات المبوبة

> **الحالة:** جاهز ومختبَر على فرع `claude/wizardly-rubin-13bt71` — **لم يُنشر على mat3tl.com بعد**. الموقع الحالي (v4) ما زال يعمل كما هو حتى دمج الفرع في `main`.

## ما الذي تغيّر

تحوّل التطبيق من دليل لمقدمي خدمات السيارات (باشتراكات شهرية) إلى سوق إعلانات مبوبة مجاني بالكامل. **نظام اشتراكات مقدمي الخدمات أُلغي من الواجهة الجديدة** (بياناته محفوظة في قاعدة البيانات ولم تُحذف).

### الواجهة (`index.html`، `js/app.js`)
- 12 قسماً بأيقونات خاصة: السيارات، العقارات، الهواتف، الإلكترونيات، الدراجات، القوارب، قطع الغيار، الأثاث، الحيوانات والطيور، الوظائف، الخدمات، المنوعات.
- التصفح والبحث والمفضلة بدون تسجيل (المفضلة تُحفظ على الجهاز وتُنقل للحساب عند التسجيل).
- التسجيل برقم الهاتف + كلمة سر، ويُطلب فقط عند إضافة إعلان.
- إضافة إعلان مجاناً: حتى 10 صور (تُضغط تلقائياً)، العنوان، خانات خاصة بكل قسم، السعر (ثابت / قابل للتفاوض / على السوم / مجاناً)، المنطقة (84 منطقة في 6 محافظات)، الوصف.
- اتصال مباشر وزر واتساب برسالة جاهزة فيها رابط الإعلان.
- بحث نصي + فلترة بالقسم والسعر والمنطقة أو المحافظة وخانات القسم (مثل الشركة والحالة) + فرز بالأحدث أو السعر. الأحدث أولاً افتراضياً.
- إدارة إعلاناتي: تعديل، حذف (مع حذف الصور)، تحديد كمباع، إخفاء، إعادة تفعيل، ورفع الإعلان للأعلى مرة كل 24 ساعة.
- الإبلاغ عن إعلان مخالف (متاح للزوار أيضاً، مع حد للتكرار).
- عربي / English بتبديل فوري (اتجاه الصفحة يتغير تلقائياً).
- PWA قابل للتثبيت على الآيفون والأندرويد.

### لوحة الإدارة (`admin.html`، `js/admin.js`)
| القسم | الوظائف |
|---|---|
| الإحصائيات | إعلانات نشطة/اليوم/الأسبوع/مباعة/قيد المراجعة/موقوفة، المستخدمون والجدد والمحظورون، المشاهدات والاتصالات والواتساب، رسم لآخر 14 يوم، توزيع حسب القسم والمحافظة |
| الإعلانات | بحث بالعنوان أو رقم الإعلان أو الهاتف، فلترة بالحالة والقسم والمستخدم، تفعيل، إيقاف مع سبب (يصل إشعار للمعلن)، إخفاء، إرجاع للمراجعة، تمييز بعدد أيام، حذف نهائي مع الصور |
| البلاغات | مفتوحة/معالجة/مرفوضة، إيقاف الإعلان مباشرة أو رفض البلاغ |
| المستخدمون | بحث بالاسم أو الهاتف، حظر مع سبب (يوقف إعلاناته ويسجّل خروجه فوراً)، فك الحظر (يعيد إعلاناته)، تغيير الصلاحية (مستخدم / مشرف / مدير — المدير يمنحه المالك فقط) |
| الأقسام والخانات | إضافة قسم، تعديل الاسم (عربي/إنجليزي) والأيقونة والترتيب والتفعيل، نوع خانة السعر (سعر/راتب/إيجار)، محرر خانات كامل (قائمة/نص/رقم، إلزامية، فلتر سريع، الخيارات) |
| المناطق | إضافة منطقة، إيقاف/تفعيل |
| الإعدادات | مراجعة الإعلانات قبل النشر، الحد اليومي للإعلانات، الإخفاء التلقائي بعد عدد بلاغات، أقصى عدد صور، **تفعيل الإعلانات المدفوعة (التمييز) وأسعارها**، رقم واتساب الدعم |

**الإعلانات المدفوعة:** جاهزة ومعطّلة افتراضياً. عند تفعيلها من الإعدادات يظهر قسم «إعلانات مميزة» في الرئيسية والأقسام، ويظهر للمعلن زر «ميّز إعلانك» بالأسعار ليتواصل عبر واتساب، ثم يميّز المدير الإعلان من قسم الإعلانات. يمكن لاحقاً ربط بوابة دفع بنفس العمود `featured_until`.

كل التغييرات **إضافية** ولم تُعدَّل أو تُحذف أي بيانات قديمة. ملفات SQL في `supabase/migrations/`.

| Migration | المحتوى |
|---|---|
| `backup_20261124_before_v5_marketplace` | نسخة احتياطية كاملة في schema `backup_20261124_v5`: كل جداول public (39 جدول) + السياسات + الدوال + الـ triggers + قائمة ملفات التخزين + تعريف الأعمدة |
| `v5_marketplace_core` | `profiles.is_banned`، جداول `kw_areas` و`market_categories` و`market_ads` مع RLS وصلاحيات أعمدة و trigger الحماية `guard_market_ad` |

| `v5_marketplace_grants_storage_settings` | صلاحيات الدوال، bucket `market` للصور (2MB، صور فقط) وسياساته، إعدادات `market` و`paid_ads` |
| `v5_seed_categories` | الأقسام الـ12 وخاناتها |
| `v5_table_grants`، `v5_stats_metrics` | صلاحيات القراءة للجداول الجديدة، ومقاييس الإحصائيات `m_*` |

### الحماية
- المستخدم لا يقدر يغيّر رقم الهاتف في الإعلان (يُؤخذ من رقم الحساب في الخادم)، ولا العدادات، ولا التمييز، ولا مالك الإعلان (صلاحيات أعمدة + trigger).
- الصور مقبولة فقط من مجلد صاحب الإعلان في bucket `market`.
- الإعلان «قيد المراجعة» أو «الموقوف» لا يقدر صاحبه يعيد تفعيله.
- المحظور لا يقدر ينشر أو يعدّل أو يرفع صوراً (RLS)، وتُسحب جلساته فوراً.
- كل دوال الإدارة تتحقق من الصلاحية داخل الخادم؛ حساب المالك والشريك محميان من الحظر وتغيير الصلاحية.
- حد يومي للإعلانات لكل مستخدم، وحد للبلاغات لكل جهاز/مستخدم، وإخفاء تلقائي للإعلان بعد عدد بلاغات.

## الاختبارات المنفذة (على قاعدة البيانات الحقيقية بحسابات تجربة حُذفت بعدها)
- تسجيل جديد برقم الهاتف من شاشة «أضف إعلان» ← نشر إعلان سيارة بصورتين وكل الخانات ← ظهوره في الرئيسية والقسم والبحث والفلاتر (الشركة، المحافظة، نطاق السعر).
- تحديد كمباع، إعادة تفعيل، رفع (رُفض بشكل صحيح قبل 24 ساعة)، تعديل العنوان وتغيير صورة الغلاف، حذف الإعلان مع صوره.
- زائر: مفضلة، إبلاغ.
- مدير: الإحصائيات، إيقاف الإعلان من البلاغ، تفعيله، حظر المستخدم (اختفى إعلانه ومُنع من النشر)، فك الحظر (عاد الإعلان)، حفظ قسم، حفظ الإعدادات، تمييز إعلان.
- اختبارات اختراق عبر الـ API: تعديل العدادات/الرقم/إعلان الغير، صور من خارج التخزين، استدعاء دوال الإدارة، ترقية النفس لمدير — **كلها مرفوضة**.
- الواجهة بالعربي والإنجليزي على مقاسات آيفون وأندرويد وسطح المكتب، بدون أخطاء في المتصفح.

## خطوات النشر
1. دمج الفرع `claude/wizardly-rubin-13bt71` في `main` ← GitHub Pages ينشر تلقائياً على mat3tl.com خلال دقيقة.
2. فتح mat3tl.com على الجوال وتجربة نشر إعلان، ثم `mat3tl.com/admin.html` بحساب المالك.
3. التطبيق المثبّت عند العملاء يتحدث تلقائياً (Service Worker جديد بإصدار `m5-v5.0.0`).

**التراجع:** إرجاع commit الدمج في `main` يعيد v4 فوراً (قاعدة البيانات متوافقة مع النسختين). ملفات v4 محفوظة أيضاً في `backup/v4-site-2026-11-24/`.

## ملاحظات مهمة قبل الإطلاق الواسع
- **التحقق من رقم الهاتف:** التسجيل الحالي برقم الهاتف وكلمة سر بدون رسالة SMS (نفس نظام v4)، أي أن الرقم غير مُتحقق منه. لمنع تسجيل أرقام الآخرين يُنصح بربط مزوّد SMS (مثل Twilio) في Supabase Auth وتفعيل OTP — يحتاج حساباً لدى المزوّد.
- يُنصح بتفعيل *Leaked password protection* من إعدادات Supabase Auth.
- جداول v4 القديمة (الشركات، الاشتراكات، الطلبات...) باقية بدون استخدام في الواجهة الجديدة؛ يمكن حذفها لاحقاً بعد التأكد.
