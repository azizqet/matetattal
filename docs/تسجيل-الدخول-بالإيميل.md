# تسجيل الدخول في ماتعطل: الإيميل وكلمة المرور

اعتُمد هذا النظام في 23 نوفمبر 2026. **لا يوجد دخول برقم الهاتف ولا رسائل SMS** (أُلغيت دالة `send-sms` ومزود kwtSMS).

## كيف يعمل
- **التصفح بدون حساب:** أي أحد يقدر يشوف الخدمات والشركات والإعلانات، ويتصل أو يراسل واتساب.
- **الحساب مطلوب فقط** لإضافة إعلان، وطلب خدمة، والمفضلة، والدعم الفني.
- **حساب جديد:** الاسم + الإيميل + كلمة المرور (8 خانات فيها حروف وأرقام) + الموافقة على الشروط.
- **تسجيل الدخول:** الإيميل + كلمة المرور. المدير تفتح له لوحة الإدارة تلقائياً.
- **نسيت كلمة المرور:** رابط على الإيميل يفتح صفحة «كلمة مرور جديدة» داخل التطبيق.
- الحسابات الموجودة كلها بالإيميل، وتدخل مثل ما هي بدون أي تغيير.

## أرقام التواصل (للمعلن)
- **رقم الاتصال:** 8 أرقام، يبدأ بـ 2 أو 5 أو 6 أو 9.
- **رقم الواتساب:** «نفس رقم الاتصال» أو «رقم مختلف»، وهو جوال يبدأ بـ 5 أو 6 أو 9.
- **أين تُدخل:** في نموذج الإعلان، وفي لوحة الإدارة ← الشركات ← «أرقام التواصل».
- **الأزرار:** «اتصال» يفتح تطبيق الهاتف على `tel:+965XXXXXXXX`، و«واتساب» يفتح محادثة على `https://wa.me/965XXXXXXXX`.
- **أرقام العملاء وبيانات دخولهم ما تظهر للعامة:** جداول `profiles` و `service_requests` و `support_*` محمية بـ RLS.

## إعدادات Supabase المطلوبة (مرة واحدة، من لوحة Supabase)
1. Authentication ← Sign In / Providers:
   - **Email:** مفعّل.
   - **Phone:** أوقفه (Disable).
2. Authentication ← Auth Hooks: أوقف **Send SMS hook** إذا كان مفعّلاً.
3. Edge Functions: احذف دالة `send-sms` إذا كانت منشورة، واحذف أسرار `KWTSMS_*` و `SEND_SMS_HOOK_SECRET`.
4. Authentication ← URL Configuration ← Redirect URLs: أضف `matetattal://auth-callback`، حتى تفتح روابط التفعيل واستعادة كلمة المرور داخل التطبيق.
5. **(مهم قبل النشر)** Authentication ← Emails ← SMTP Settings: اربط مزود إيميل.
   - بريد Supabase المدمج محدود برسائل قليلة بالساعة، ومخصّص للتجربة فقط.
   - فيه مزودين عندهم باقة مجانية، مثل Resend و Brevo. تأكد من حدود الباقة المجانية في موقع المزود.
