# تفعيل الدخول برقم الجوال (OTP عبر SMS) — ماتعطل

## كيف يعمل
1. «حساب جديد»: التلفون (+965 ثابت، 8 أرقام) + الاسم + البريد + كلمة المرور ← «سوّ حسابي».
2. Supabase Auth ينشئ الحساب **غير مفعّل** ويرسل رمز تحقق (6 أرقام) — يستدعي دالة `send-sms` عبر «Send SMS Hook» موقّع.
3. الدالة ترسل الرسالة عبر بوابة **kwtsms.com** الكويتية.
4. المستخدم يدخل الرمز (أو يُعبّأ تلقائياً) ← يتفعّل الحساب ويدخل مباشرة.
5. «عندك حساب؟ سجّل دخولك»: التلفون + كلمة المرور (والحسابات القديمة بالبريد تكتب بريدها في نفس الخانة).
6. «نسيت كلمة المرور؟»: رمز SMS ← كلمة مرور جديدة.

المفاتيح السرية لا توجد في التطبيق أبداً؛ تُحفظ فقط في أسرار Supabase.

## المطلوب من المالك (مرة واحدة)
### 1) حساب kwtsms
- التسجيل في https://www.kwtsms.com (مجاني للتجربة).
- اسم مرسل للرسائل التشغيلية (Transactional Sender ID): 14.950 د.ك مرة واحدة — يحتاج رخصة تجارية والبطاقة المدنية للمفوّض بالتوقيع (≈ 5 أيام عمل).
- رصيد: 0.015 د.ك للرسالة (حد أدنى 1,000 رسالة = 15 د.ك).
- من صفحة API في حساب kwtsms: انسخ **API username** و **API password** (ليست بيانات الدخول).

### 2) أسرار الدالة في Supabase
Edge Functions ← Secrets ← أضف:
| الاسم | القيمة |
|---|---|
| `KWTSMS_USERNAME` | API username |
| `KWTSMS_PASSWORD` | API password |
| `KWTSMS_SENDER` | اسم المرسل المعتمد حرفياً |
| `KWTSMS_TEST` | `1` أولاً للتجربة، ثم `0` للإرسال الحقيقي |
| `SEND_SMS_HOOK_SECRET` | من الخطوة 3 |

### 3) ربط Supabase Auth بالدالة
- Authentication ← Sign In / Providers ← **Phone** ← تفعيل (Enable) **مع تفعيل «Confirm phone»** (حتى لا يُفعَّل الحساب قبل الرمز).
- اترك **Email** مفعّلاً (لدخول الحسابات القديمة بالبريد).
- Authentication ← **Auth Hooks** ← Send SMS hook ← تفعيل ← النوع HTTPS ← الرابط:
  `https://xpnwhvbxordtsmnegvri.supabase.co/functions/v1/send-sms`
  ← انسخ «Secret» الذي يولّده Supabase وضعه في `SEND_SMS_HOOK_SECRET`.
- Authentication ← Rate Limits: راجع حد رسائل SMS بالساعة وحد محاولات التحقق.
- (اختياري) مدة صلاحية الرمز: Providers ← Phone ← OTP expiry (مثلاً 300 ثانية)، وطول الرمز 6.

## الاختبار (لا يُعتبر النظام جاهزاً قبله)
1. مع `KWTSMS_TEST=1`: أرسل رمزاً من التطبيق ← يجب أن تظهر الرسالة في «Queue» بحساب kwtsms دون وصولها.
2. غيّر إلى `KWTSMS_TEST=0` ← أرسل رمزاً لرقمك ← تأكد من وصول SMS، وإدخال الرمز، والدخول، وإنشاء الحساب.
3. أعد المحاولة بعد أقل من 60 ثانية ← يجب أن يُرفض الإرسال.
4. أدخل رمزاً خاطئاً عدة مرات ← يجب أن يُرفض.
