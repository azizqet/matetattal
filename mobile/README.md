# تطبيق ماتعطل — أندرويد وآيفون

تطبيق أصلي (Native) مبني بـ **Capacitor 8**، يضم ملفات تطبيق ماتعطل داخله (لا يحمّل الموقع من الإنترنت)، ويتصل بنفس قاعدة بيانات Supabase.

| | |
|---|---|
| المعرّف | `com.mat3tl.app` |
| الاسم | ماتعطل |
| الإصدار | 5.0.2 (رقم البناء 502) |
| أندرويد | الحد الأدنى Android 7 (API 24)، الهدف API 36 |
| آيفون | الحد الأدنى iOS 15 |

## مزايا التطبيق الأصلي
- أيقونة وشاشة بداية بهوية ماتعطل (أندرويد 12+ وما قبله، والآيفون).
- شريط الحالة يتلوّن حسب الصفحة (أزرق في الرئيسية، أبيض في باقي الصفحات).
- زر الرجوع في أندرويد: يغلق النافذة المفتوحة ← يرجع صفحة ← يخرج من التطبيق في الرئيسية.
- المشاركة من قائمة المشاركة الأصلية للجوال، والروابط المشاركة تفتح `https://mat3tl.com/#/ad/...`.
- اهتزاز خفيف عند الإضافة للمفضلة.
- روابط `mat3tl.com` تفتح داخل التطبيق في أندرويد (App Links، ملف التحقق `/.well-known/assetlinks.json`).
- الاتصال والواتساب يفتحان تطبيق الهاتف وواتساب مباشرة.
- اختيار الصور من الألبوم أو الكاميرا (مع رسائل الأذونات بالعربي في الآيفون).

## البناء
```bash
cd mobile
npm install
npm run sync          # ينسخ ملفات الواجهة من جذر المستودع إلى www/ ثم يحدّث مشروعي أندرويد وآيفون
```
أي تعديل على الواجهة يتم في جذر المستودع (`index.html`، `js/`، `css/`) ثم `npm run sync` قبل كل بناء.

### أندرويد
يتطلب Java 21 و Android SDK 36.
```bash
cd mobile/android
./gradlew bundleRelease   # app/build/outputs/bundle/release/app-release.aab  ← للرفع على Google Play
./gradlew assembleRelease # app/build/outputs/apk/release/app-release.apk   ← للتثبيت المباشر
```
التوقيع يُقرأ من `mobile/android/keystore.properties` (غير محفوظ في المستودع):
```
storeFile=/المسار/matetattal-upload.jks
storePassword=...
keyAlias=matetattal
keyPassword=...
```
> **مهم جداً:** احفظ ملف المفتاح `matetattal-upload.jks` وكلمة سره في مكان آمن (مثل مدير كلمات سر + نسخة احتياطية). بدونه لا يمكن رفع تحديثات للتطبيق إلا بطلب إعادة تعيين من Google.

### آيفون
يتطلب جهاز **Mac** فيه **Xcode 16+** وحساب Apple Developer.
```bash
cd mobile && npm install && npm run sync && npx cap open ios
```
في Xcode: اختر الـ Team من *Signing & Capabilities* ← *Product → Archive* ← *Distribute App → App Store Connect*.

## النشر في المتاجر

### Google Play (رسوم 25$ مرة واحدة)
1. أنشئ حساباً في Google Play Console وأنشئ تطبيقاً باسم «ماتعطل».
2. ارفع `app-release.aab` في *Production* (أو *Internal testing* أولاً).
3. فعّل **Play App Signing** (افتراضي).
4. بعد الرفع: من *Setup → App signing* انسخ بصمة **SHA-256 لمفتاح توقيع التطبيق** وأضفها إلى `/.well-known/assetlinks.json` بجانب البصمة الموجودة، حتى تفتح روابط mat3tl.com داخل التطبيق.
5. المطلوب في صفحة المتجر: وصف، لقطات شاشة، أيقونة 512، صورة 1024×500، رابط سياسة الخصوصية (`https://mat3tl.com/#/terms`)، وتعبئة نموذج أمان البيانات (رقم الهاتف والاسم والصور التي يرفعها المستخدم).

### App Store (99$ سنوياً)
1. حساب Apple Developer وإنشاء التطبيق في App Store Connect بالمعرّف `com.mat3tl.app`.
2. البناء والرفع من Xcode (أعلاه).
3. نفس بيانات المتجر، مع ملاحظة: Apple تشترط وجود **حذف الحساب داخل التطبيق** (موجود في «حسابي») و**الإبلاغ عن المحتوى** (موجود في كل إعلان).
