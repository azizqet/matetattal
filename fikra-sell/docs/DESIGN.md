# FIKRA SELL · نظام التصميم (الإصدار 2)

تصميم عصري هادئ وبسيط على خلفية بيضاء، مستوحى في **تنظيم الأقسام وسهولة التصفح وطريقة عرض الإعلانات** من تطبيقات الإعلانات المبوبة الكويتية، بهوية مستقلة تماماً مبنية على ألوان شعار «فكرة سيل».

## 1. الشعار
- الشعار الرسمي يُضاف كملف أصلي في `brand/source/fikra-logo.png` ثم:
  `python3 brand/tools/extract_palette.py && node brand/tools/build_assets.mjs` (من داخل `app/`)
  ← يُستخرج اللون الدقيق من البكسلات، ويُربط الملف كما هو دون أي تعديل أو إعادة رسم في التطبيق والأيقونات وشاشة البداية.
- إلى حين إضافة الملف: يُعرض الاسم «سيـ فكرة ـل» نصّاً (فكرة بالتركوازي، سيـ/ـل بالأسود). **لا يوجد أي شعار مولَّد.**
- المكوّن: `app/src/components/Brand.tsx → <Lockup/>`، `<FikraLogo/>`.

## 2. الألوان (`app/src/theme/brand.generated.ts` + `tokens.ts`)
| الدور | اللون المؤقت | الاستخدام |
|---|---|---|
| `primary` | `#00857D` تركوازي (تباين 4.5:1 مع الأبيض) | الأزرار، التنقل، الأسعار، الأيقونات، الروابط |
| `primaryBright` | `#00B3A7` | لمسات خفيفة (خطوط الكشيدة، مؤشرات الصور) |
| `featured` | `#FFC629` أصفر | **الإعلانات المميزة فقط** (شارة «مميز» وإطار البطاقة) |
| `alert` / `danger` | `#D32F2F` أحمر | **التنبيهات فقط**: الأخطاء، عدّادات غير المقروء، الحذف |
| `ink` | `#111111` | النصوص |
| الخلفية | `#FFFFFF` | خلفية كل الشاشات، وبقية الدرجات رماديات محايدة |

الوضع الداكن يستخدم نفس الأدوار مع تفتيح التركوازي. كل الأزواج مختبرة آلياً لمعيار WCAG AA (`__tests__/logic.test.ts`).

## 3. الأشكال والمسافات
زوايا موحّدة: `sm 10`، `md 12` (البطاقات والحقول والأزرار)، `lg 16` (لوحات الأقسام)، `pill`. حدود رفيعة 1px بلون `line`؛ بلا ظلال ثقيلة.

## 4. الأيقونات
`app/src/components/Icon.tsx`: عائلة واحدة بخط 1.75 على شبكة 24، لون واحد. أيقونات الأقسام الـ12 تُعرض بالتركوازي على لوحة تركوازية فاتحة:
car · building · mobile · sofa · paw · sheep · tent · hanger · briefcase · wrench · excavator · grid.

## 5. الشاشات
- **الرئيسية**: الشعار + المفضلة والإشعارات ← بحث بإطار تركوازي وزر «بحث» ← اختيار المحافظة/المنطقة (يُحفظ على الجهاز ويُطبَّق على المميزة والأحدث) ← شبكة الأقسام 4×3 ← بنرات ← الإعلانات المميزة (شريط أفقي بصور كبيرة) ← أحدث الإعلانات (شبكة/قائمة).
- **بطاقة الإعلان**: صورة كبيرة، السعر بالدينار بخط عريض تركوازي، العنوان سطرين، المنطقة. المميز: إطار وشارة صفراء.
- **الأقسام**: شبكة 3 أعمدة مع عدد الإعلانات/الأقسام الفرعية.
- **صفحة القسم**: رأس القسم + اختيار المنطقة + بطاقات الأقسام الفرعية الأفقية + الفلاتر الخاصة بكل قسم + حفظ البحث.
- **أضف إعلان**: 3 خطوات فقط: القسم ← الصور والتفاصيل ← السعر والموقع والتواصل مع معاينة مختصرة والنشر.
- **الشريط السفلي**: الرئيسية · الأقسام · (أضف إعلان: دائرة تركوازية) · المحادثات · حسابي.
