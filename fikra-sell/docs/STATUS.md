## المتطلبات الخارجية المتبقية
1. **ملف شعار «فكرة» الأصلي** (PNG بدقة عالية) — لم يصل مع الرسالة.
2. **مشروع Supabase مستقل** — الحساب المجاني وصل لحد مشروعين (ماتعطل، fazza). الحل: إيقاف مشروع مؤقتاً، أو ترقية الخطة (قرار مالي لك).
3. **مستودع GitHub جديد `azizqet/fikra-sell`** — صلاحيات هذه الجلسة لا تسمح بإنشاء مستودعات. أنشئه فارغاً وسأنقل الملفات إليه.
4. **App Store Connect API Key** (أو تسجيل الدخول لـ EAS) لبناء iOS ورفعه إلى TestFlight.
5. **حساب Google Play Console** لرفع AAB.
